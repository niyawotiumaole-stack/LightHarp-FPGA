# LightHarp-FPGA — 光影弦琴

我们基于高云 FPGA 开发了一款八声部光影弦琴，支持红外交互、超声波音色控制与 OLED 状态显示。

## 我们当前提交的版本

我们当前提交的版本包含八声部、八路红外输入、EC11 旋转编码器、超声波表情控制和 OLED 显示。

我们使用 Tang Mega 60K NEO 开发板，FPGA 器件为 GW5AT-60B，系统时钟为 50 MHz。

我们采用独立相位振荡器与 ADSR 包络，支持正弦波和三角波音色。当前版本不是 Karplus-Strong 物理建模版本。

当前顶层参数如下：

| 参数 | 当前值 |
| --- | --- |
| N | 8 |
| TEST_MODE | 0 |
| ECHO_ENABLE | 0 |
| EXPR_ENABLE | 1 |

我们在部分 RTL 文件中保留了扩展能力，但当前配置未启用回声，尚不将其列为已完成验收的功能。

## 我们的构建方式

我们保留整个目录结构，使 Gowin 工程能够通过相对路径引用源码与约束。

我们在重建时将完整工程解压到纯英文路径，例如 `D:/LightHarp8_OLED`，再使用 Gowin V1.9.12.03 编译。

我们通过 `gw_sh.exe` 执行 `03_projects/harp8oled/build.tcl`。脚本包含 `use_cpu_as_gpio` 设置，用于避免 CPU 复用引脚布局错误。

我们通过 `04_sim/run_oled.ps1` 运行仿真，可使用 `-VivadoBin` 指定本机的 Vivado bin 路径。
